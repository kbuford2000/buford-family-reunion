HOW TO USE THIS WITH GOOGLE SITES
----------------------------------
Option A (Recommended) — Embed as iframes:
  1. Upload each HTML file to Google Drive
  2. Publish each file (right-click → Share → Anyone with link)
  3. In Google Sites, use Insert → Embed → paste the file URL

Option B — Use as a reference/visual guide:
  1. Open each HTML file in your browser to see the design
  2. Recreate the layout in Google Sites page by page
  3. Use the content (text, dates, names) directly from these files
